# 語音點名系統

上課用的網頁版語音點名工具：上傳 Excel 名單後，系統每 3 秒唸出一位學生姓名，學生沒到就按「缺席」。點完名後，結果會**自動存入你 Google 雲端硬碟裡的試算表**，之後直接打開試算表就能看歷次紀錄。

## 檔案說明

| 檔案 | 用途 | 放在哪裡 |
|---|---|---|
| `index.html` | 點名網頁 | GitHub |
| `README.md` | 說明文件 | GitHub |
| `Code.gs` | Google 試算表接收端 | 貼到 Google 試算表的 Apps Script（**不要**放 GitHub） |

## 功能

- **上傳名單**：支援 .xlsx／.xls／.csv，需含「姓名」欄，「學號」「座號」欄可有可無
- **語音點名**：每位間隔 2～6 秒（預設 3 秒），可選唸法與語速
- **標記狀態**：缺席、遲到、請假；時間到未標記者自動記為出席；反應不及可按「上一位缺席」補標
- **自動存入 Google 試算表**：點名結束、暫停或事後修改狀態時自動寫入；網路不通時先留在瀏覽器，恢復連線後自動補存
- **試算表內容**：
  - 「點名紀錄」工作表：每次點名的完整明細（日期、課程、座號、學號、姓名、狀態）
  - 「總表-課程名稱」工作表：每門課一張，學生 × 日期，最後三欄是缺席、遲到、請假次數；缺席自動標紅色

## 一、部署網頁到 GitHub Pages

1. 登入 GitHub，按右上角「+」→「New repository」，名稱例如 `rollcall`，選 **Public**，按「Create repository」。
2. 點「uploading an existing file」，把 `index.html` 和 `README.md` 拖進去，按「Commit changes」。
3. 進入「Settings」→ 左側「Pages」→ Source 選「Deploy from a branch」，Branch 選 `main`、資料夾 `/ (root)`，按「Save」。
4. 等 1～2 分鐘，網址會是 `https://你的帳號.github.io/rollcall/`。

## 二、建立 Google 試算表接收端（只需做一次）

1. 到 Google 雲端硬碟新增一份 Google 試算表，命名例如「點名紀錄」。
2. 在試算表上方選「擴充功能」→「Apps Script」。
3. 刪掉編輯器內原有的內容，把 `Code.gs` 整份貼上。
4. 修改第 8 行的密碼，例如：`const TOKEN = 'mcu-rollcall-2026';`，然後按儲存（磁碟片圖示）。
5. 按右上角「部署」→「新增部署作業」→ 齒輪選「網頁應用程式」：
   - 執行身分：**我**
   - 誰可以存取：**所有人**
6. 按「部署」，第一次會要求授權：選你的 Google 帳號 →「進階」→「前往（未驗證的專案）」→「允許」。這是你自己寫的程式，所以 Google 會顯示未驗證，屬正常現象。
7. 複製畫面上的「網頁應用程式網址」（`https://script.google.com/macros/s/…/exec`）。

## 三、在點名網頁連線（每台電腦／瀏覽器設定一次）

1. 打開點名網頁，展開「自動存到 Google 試算表」→「連線設定」。
2. 貼上剛才的網址，輸入第二步設定的密碼，按「儲存並測試連線」。
3. 顯示「已連線 Google 試算表」就完成了，之後會出現「開啟我的點名試算表」連結。

## 快捷鍵

| 按鍵 | 功能 |
|---|---|
| 空白鍵 | 目前這位缺席（再按一次取消） |
| L | 遲到 |
| B | 上一位缺席 |
| Enter | 開始／暫停 |
| ← → | 上一位／下一位 |
| R | 重唸 |

## 注意事項

- **學生名單、Apps Script 網址和密碼都不要放到 GitHub。** Public repository 任何人都看得到。網址與密碼只存在你的瀏覽器裡。
- 「誰可以存取：所有人」的意思是任何拿到網址的人都能呼叫這支程式，但沒有正確密碼就寫不進去。密碼請不要設得太簡單。
- 日後如果修改了 `Code.gs`，要到「部署」→「管理部署作業」→ 鉛筆圖示 → 版本選「新版本」→「部署」，修改才會生效（網址不變）。
- 建議使用 Chrome 或 Edge（中文語音較完整）。
- CSV 名單請存成 UTF-8 編碼，否則中文會亂碼；用 .xlsx 最保險。
